# 딤레이스(Dimraeth) 번역 개선 패치

딤레이스는 이미 공식 한국어 번역이 들어있는 게임입니다. 이 패치는 번역을 새로
만드는 게 아니라, 기존 공식 번역에서 **잘못 들어간 부분**을 찾아 고친 수정 패치입니다.

## 추천 대상

- 게임 안에서 NPC 이름표가 "라하너가 중얼거린다." 처럼 문장으로 뜨는 걸 이상하게
  느낀 적이 있는 분
- 메인 스토리(데모) 완료 후 안내 메시지가 한국어가 아니라 알 수 없는 외국어로
  뜨는 걸 본 분
- 그냥 조금이라도 더 다듬어진 한국어로 플레이하고 싶은 분

번역 문장 자체(대사, 퀘스트 설명 등)는 이미 품질이 좋은 편이라 손대지 않았습니다.

## 설치 / 제거 방법 (설치 프로그램 하나로 둘 다 처리됩니다)

1. 압축을 통째로 아무 폴더에나 풉니다.
2. `KR_Patch.vbs` 를 더블클릭합니다.
3. Windows 보안 창(사용자 계정 컨트롤, UAC)이 뜨면 **[예]** 를 눌러주세요.
   게임 폴더가 `Program Files` 안에 있어서 관리자 권한이 필요합니다.
4. 현재 상태에 따라 자동으로 안내가 뜹니다.
   - 아직 설치 안 된 상태 → "설치하시겠습니까?" → 예 → 설치
   - 이미 설치된 상태 → "제거(원본으로 되돌리기)하시겠습니까?" → 예 → 제거

설치 프로그램이 스팀 라이브러리 경로를 자동으로 찾습니다. 못 찾으면 게임 폴더
경로를 직접 입력하라는 창이 뜹니다. 설치 중 문제가 있으면 `Console.bat` 을
대신 실행해서(마찬가지로 관리자 권한으로 실행) 오류 내용을 눈으로 확인해
주세요. 오류 내용은 스크립트와 같은 폴더의 `error_log.txt` 에도 저장됩니다.

원본 파일은 설치 시 자동으로 `sharedassets1.assets.bak` 으로 백업되고,
제거 시 이 백업으로 복원됩니다.

## 주의 사항

- 관리자 권한(UAC) 창에서 [아니오]를 누르면 설치/제거가 진행되지 않습니다.
  `KR_Patch.vbs` 를 다시 실행해서 [예]를 눌러주세요.
- 스팀 업데이트가 오면 게임 파일이 패치 전 상태로 되돌아갈 수 있습니다. 업데이트
  후 패치가 사라진 것 같으면 설치 프로그램을 다시 실행해 주세요.
- 백신 프로그램이 이 패치를 오탐지할 수 있습니다. 게임 데이터 파일을 통째로
  바꿔치기하는 방식 자체가 악성코드 수법과 비슷해 보이고, 서명되지 않은 개인
  제작 스크립트라 그렇습니다. 예외 처리 목록에 패치 폴더를 추가해 주세요.
- 이 패치는 딤레이스의 특정 빌드(Unity 6000.0.61f1 기준)에 맞춰 만들어졌습니다.
  게임이 크게 업데이트되면 패치가 깨질 수 있으며, 제보 주시면 대응하겠습니다.
